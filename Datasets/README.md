# Datasets

This folder contains the datasets used in my Data Analytics projects.

## Available Dataset

### `zepto.csv`

This dataset contains retail product information collected from the Zepto platform and is used for SQL-based data analysis.

### Dataset Features

* SKU ID
* Product Category
* Product Name
* Maximum Retail Price (MRP)
* Discount Percentage
* Discounted Selling Price
* Available Quantity
* Product Weight
* Stock Availability
* Quantity

## Purpose

The dataset is used for:

* Data Exploration
* Data Cleaning
* Business Analysis
* Pricing Analysis
* Discount Analysis
* Inventory Analysis
* Revenue Estimation
