# SQL Source Code

This folder contains the SQL scripts used for data analysis projects developed as part of my Data Analytics Portfolio.

##  File Included

### `zepto_SQL_project.sql`

This SQL script contains the complete workflow for the **Zepto Retail Data Analysis** project, including:

* Database table creation
* Data exploration queries
* Data cleaning operations
* Business analysis queries
* Revenue analysis
* Discount analysis
* Inventory analysis
* Product categorization
* Aggregate and reporting queries

The script was developed using **PostgreSQL** and executed in **pgAdmin 4**.

## Technologies

* PostgreSQL
* SQL
* pgAdmin 4
