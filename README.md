# Zepto SQL Analysis

## Project Overview

This project demonstrates end-to-end data analysis using **PostgreSQL** on a Zepto retail products dataset. The analysis focuses on data exploration, data cleaning, and business-oriented SQL queries to generate actionable insights related to pricing, discounts, inventory, and product categories.

The project is designed to showcase practical SQL skills required for Data Analyst roles.

---

## Technologies Used

* PostgreSQL
* pgAdmin 4
* SQL

---


## Project Objectives

* Create a relational table in PostgreSQL.
* Perform exploratory data analysis on retail product data.
* Clean and validate the dataset.
* Analyze discounts, pricing, and inventory.
* Generate business insights using SQL queries.

---

## Analysis Performed

### Data Exploration

* Counted total number of products
* Displayed sample records
* Checked for missing values
* Listed unique product categories
* Analyzed stock availability

### Data Cleaning

* Removed records with invalid MRP values
* Standardized pricing values for analysis

### Business Analysis

* Top 10 products with the highest discounts
* Premium products currently out of stock
* Estimated revenue by category
* High-priced products with low discounts
* Categories with the highest average discounts
* Best value products based on price per gram
* Product weight classification
* Total inventory weight by category

---

## Key Insights

* Identified products offering the highest discounts.
* Highlighted premium products that are unavailable in stock.
* Estimated revenue contribution across different categories.
* Compared discount strategies among product categories.
* Evaluated products based on price efficiency.
* Analyzed inventory distribution for warehouse planning.

---

## Business Recommendations

* Replenish inventory for premium out-of-stock products.
* Promote highly discounted products to attract customers.
* Focus marketing efforts on top revenue-generating categories.
* Optimize pricing strategies for premium products.
* Improve warehouse planning using inventory weight analysis.
